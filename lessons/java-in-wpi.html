Page 1: Double and Static Type

Java has several variable types to store numbers, but in this lesson we'll focus on three: int, float, and double. Int is used to store whole number values for motor or port IDs. We use the type double to store all other values instead of float. A float only stores 4 bytes of data, while a double stores 8 bytes. This allows our variables to be as precise as possible.

For example, let's say you had a simple script to calculate the area of a circle. If you had your pi variable as an int, you could store only 3. If you had it as a float, you could store up to about 3.1415927 with more limited precision. The double type will allow us to use the more precise variable 3.141592653589793.

Static Type

The class Constants stores all the variables for the codebase. We declare these variables with the static modifier, which means there is only one copy of each variable shared across all instances of the class. This allows other classes to access the same value without creating an instance of the Constants class. This is done so we only have 1 value for our variables. We don't want to have separate motorSpeed variables, for example, used in different classes. We need one value for our motorSpeed across all classes.

We can also use static methods and classes. Similar to a static variable, a static method belongs to the class it is declared in rather than an object, meaning it can be called without creating an instance of the class. We can also use static nested classes, which are classes declared inside of another class that do not require an instance of the outer class to be called. Static methods are typically used to perform a specific action, while a static nested class is used to define another type of object, that is still related to the outside class.

Finally, we can also import static classes and methods statically using import static. This allows us to use methods and variables without having the class name as a prefix. Note that doing this may make it harder to understand where variables came from.

Page 3: Final Keyword

You may have also noticed some variables, methods, and classes have the keyword final. Variables with the keyword final cannot be changed after being assigned. Let's take a look at our example of pi from earlier in the lesson:

Since the value of pi should never change, we can add the final keyword. It is important to note that the final keyword is not required, but it acts as a safety net to prevent it from being assigned to a different value.

Additionally, if we want one shared copy of pi across the whole program instead of a separate copy per object, we can add the static keyword. The static final pi, or a constant, is now a value that is assigned once across the entire code, and is never modified.

Almost all of our variables stored in Constants are applied with the public static final keywords: it's the final keyword that makes them true constants, hence the name of the class.

Class Specific Variables

Class specific variables are typically stored with the keywords private final. We don't need other classes to access class specific variables, but we still want the one value to be unchanged in the class.

In our codebase, as well as many others, we name class specific variables with a lowercase first letter, capitalizing the first letter of each following word (camelCase). We name Constants in all capital letters separated by an underscore (SCREAMING_SNAKE_CASE).
